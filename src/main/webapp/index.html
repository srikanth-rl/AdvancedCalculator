• Use the "buttons" or "click" on the keyboard to input numbers and operators.
  • Use "Clr" button or Click "Ctrl + Backspace" to clear the input field.
  • Use "Del" button or Click "Backspace" to delete the last character.
  • Use " ** ", to calculate power. (Eg. 5**3 = 125).
  • To calculate Factorial, enter the number followed by "!" button or Click "f" on the keyboard. Supports any size up to 2,000,000!
  • To calculate Remainder, Use "mod" button.
  • To check Prime number, Use "Prime" button. Supports numbers up to 15,000 digits.
  • Click "h" or Use "History" button to see past calculated results.
  • Backend powered by Java Servlets with BigInteger precision and parallel computation.
